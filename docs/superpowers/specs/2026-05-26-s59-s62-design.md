## S59：数据洞察模块动态信息图

### 概述
在"数据洞察"模块新增 `InsightCarouselCard` 组件，横向滑动轮播展示三页全新 SVG 可视化数据。

### 文件
- **新建**：`src/components/cards/InsightCarouselCard.tsx`
- **修改**：`src/App.tsx`（在 insight 模块中引入）

### 页面内容
| 页 | 标题 | 可视化 | 数据源 |
|----|------|--------|--------|
| 1 | 饮水周律动 | 7 天水平柱状图 + 数字标注 + 星期标签 | `useWeeklyData().buckets` → hydrationCount |
| 2 | 情绪小气候 | 5 色环形情绪分布图 + 中心总计文字 | `useWeeklyData().buckets` → emotionIntensityAvg / emotionCount |
| 3 | 身体微动 | 起身/散步并排大数字 + 微型进度环 | `useWeeklyData().buckets` → standupCount, walkCount |

### 交互
- Framer Motion `drag="x"` 拖拽翻页
- `dragElastic={0.2}` 松手回弹
- 底部三个圆点页码指示器（当前页 `bg-ink-500`，其余 `bg-ink-200/50`）
- `dragConstraints` 限制不可拖出边界

### 视觉
- 卡片沿用 `card-paper` 风格
- 柱状图：`bg-ink-400` 柱体，圆角顶部
- 环形图：SVG `stroke-dasharray` + `stroke-dashoffset`，5 种情绪颜色取自 blossom/warm/gentle 色系
- 数字：`font-display` 字体，`text-3xl`

### 边界处理
- 无数据时显示："这一周还没有记录，去喝口水或记录一下心情吧"
- 数据不足 7 天时：仅展示已有天数

## S60：纸张纹理深浅随滚动变化

### 概述
利用 Framer Motion `useScroll` 控制 `body::before` 纹理层的透明度，随滚动深度微调。

### 文件
- **修改**：`src/App.tsx`（新增 useScroll + useTransform）
- **修改**：`src/index.css`（body::before 改用 CSS 变量）

### 映射曲线
| 滚动位置 | 透明度 |
|----------|--------|
| 顶部 0% | 0.020 |
| 25% | 0.035 |
| 底部 100% | 0.025 |

### 实现
```
useScroll({ container: mainRef }) → scrollYProgress
useTransform(scrollYProgress, [0, 0.25, 1], [0.020, 0.035, 0.025])
→ 写入 document.documentElement.style.setProperty('--texture-opacity', ...)
```

### CSS 变更
```css
body::before {
  opacity: var(--texture-opacity, 0.025);
}
```

### 性能
- useTransform 使用 Framer Motion 内部 RAF，不触发 React 重渲染
- 使用 `useMotionValue` 而非 `useState` 避免额外渲染

## S61：语音输入情绪记录

### 概述
在 `MoodTreeHoleCard` 的 textarea 旁新增麦克风按钮，使用 Web Speech API 实时语音转文字。

### 文件
- **修改**：`src/components/cards/MoodTreeHoleCard.tsx`

### 按钮状态机
| 状态 | 图标 | 样式 | 条件 |
|------|------|------|------|
| idle | Mic | 灰色 | 未开始识别 |
| listening | Mic + 脉冲动画 | 红色 | 正在识别中 |
| disabled | MicOff | 灰色+置灰 | 浏览器不支持 SpeechRecognition |
| error | MicOff | 灰色+tooltip | 权限被拒绝 |

### 安全约束
- 语音识别全程在浏览器端（`SpeechRecognition` 浏览器内置）
- 不录制、不上传音频
- 仅将识别结果文本填入 textarea
- 权限仅在用户点击按钮时请求（不自动弹出权限弹窗）
- 文本在用户点击"轻轻放下"后才发送 AI

### 降级策略
- `typeof SpeechRecognition === 'undefined'` 时显示 disabled 状态
- 权限拒绝时 catch `NotAllowedError`，显示 error 状态
- 识别出错时 catch `onerror`，回退到 idle 状态

### 浏览器支持
- Chrome/Edge：完全支持
- Safari：macOS 部分支持，iOS 不支持 → disabled
- Firefox：不支持 → disabled

## S62：摇一摇随机温柔鼓励

### 概述
移动端通过 `DeviceMotionEvent` 检测摇动，弹出全屏温柔句子卡片。默认关闭，需在设置中手动开启。

### 文件
- **新建**：`src/components/decorative/ShakeEncouragement.tsx`
- **新建**：`src/store/shakeEncouragementStore.ts`
- **修改**：`src/App.tsx`（在 return 中插入 ShakeEncouragement）

### Store 设计
```typescript
interface ShakeEncouragementState {
  enabled: boolean;          // 默认 false
  usedIndices: number[];    // 已展示句子索引
  toggle: () => void;
  markUsed: (index: number) => void;
  resetUsed: () => void;
}
```
- 持久化：zustand persist middleware → localStorage key `light-nurture-shake`

### 句子库（16 条，组件内常量）
```
温柔句子 = [
  "你已经做得很好了。",
  "休息一下也没关系。",
  "今天你照顾自己的次数比昨天多了一次。",
  "不需要完美，存在本身就足够了。",
  "你感受到的那些，都值得被温柔对待。",
  "停下来感受这一刻，你已经很勇敢了。",
  "没有人能一直向前，偶尔停一下也很好。",
  "你不需要和任何人比较，你走的这条路是你自己的。",
  "那些你觉得做不好的事，其实你已经尽力了。",
  "生活中总有不完美，但那也是你的一部分。",
  "此刻的你，已经很完整了。",
  "深呼吸，你已经做到了今天最重要的事——照顾自己。",
  "无论今天发生了什么，你都值得被温柔对待。",
  "小小的进步也是进步，你看到了吗？",
  "就算今天什么都没做，休息也是一种照顾自己的方式。",
  "别对自己太苛刻，你已经很棒了。",
]
```

### 触发逻辑
- `DeviceMotionEvent.accelerationIncludingGravity`
- 阈值：`Math.sqrt(x² + y² + z²) > 25` m/s²
- 冷却：5 秒内不重复触发（防误触）
- 仅在 `enabled === true` 时激活监听器
- 触发时：全屏柔光覆盖 → 句子淡入 → `useHapticFeedback().success()`
- 3 秒后自动消失，点击任意处也可关闭
- 桌面端不启用（无 DeviceMotion 支持）

### 全屏卡片视觉
- 半透明暖色背景（`bg-warm-100/90`）
- 句子用 `font-display text-2xl` 居中展示
- Framer Motion `AnimatePresence` 淡入淡出
- 底部小字 "轻养伴侣 · 摇一摇"
